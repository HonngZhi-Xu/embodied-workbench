# M3025 触觉研究工作台

v0.2.5 将用户提供的 M3025_Tactile_Workbench_Source.zip 中的研究功能接入具身工坊。
侧栏进入“触觉研究工作台”；也可打开完整研究界面。原 UR5e 数采、数据与视觉 DP 训练入口保留。

## 功能

八个研究模块：实验总览、数据集与 Episode、传感器与预处理、编码器与预训练、融合与 DP 实验、评估与失败分析、研究追溯、计划与研究产出。

支持原始附件上传下载、JSON/CSV/JSONL 数据或日志导入、Episode 标签与数据划分、预处理版本、模型与实验配置、实际曲线与指标、证据关联、报告与配置备份。
H5/NPZ 等二进制可作为原文件保留，需先转换为支持的文本结构才进行研究分析，不会执行附件代码。

## 本地服务与演示

更新仓库后重启 python -m edge_agent.server，访问 http://127.0.0.1:8787/#tactile-research。
父页面处于本地模式时，研究记录与原始附件保存于平台 data_root/tactile_lab，SQLite 管理记录，文件单独存放。
数据按记录版本检查冲突，删除为可恢复软删除；原始文件元数据由上传接口确定，不能用普通配置伪造。

线上静态版提供隔离的浏览器演示，使用当前浏览器存储。它没有迁移原独立网站的 D1/R2 数据，也不是多人云端共享记录服务。
演示与本地模式明确标识、分别存储。浏览器演示清理站点数据可能丢失记录，正式数据应导出备份并使用本地服务。

## 从平台已有数据导入

在本地研究界面选择平台已登记的资产和单个 Episode。平台只读提取已保存 M3025 77×3 测点及可用合力与时间戳，建立研究数据集／Episode 的资产引用。
活跃采集数据不能导入；超出记录大小的长片段不会静默截断，应先按 Episode 划分或明确转换。
导入不会修改原 Zarr、采集程序或训练项目，不会重复打开相机和触觉串口。

测点 counts 与独立三维合力 N 分别记录。未知单位、时钟和采样信息保持未知，不能因预处理模板默认值而自动视为已标定。
77 点网格按通道索引显示，不宣称还原真实传感器物理几何。

## 研究功能边界

Masked Force、Net Force、Spatial MLP、GRU、接触门控与 Dynamics 是研究配置和追溯功能。
保存配方不会执行 GPU 预训练，不会自动把新编码器接入原 Diffusion Policy，也不会控制机器人。
现有 DP 训练入口保留其原参数和数据门控，实际新算法、权重、损失曲线与部署效果需要后续独立实现与实验验证。
评估只根据用户导入的实际日志计算，不合成成功率、特征嵌入或训练结果。

## 构建与来源

研究客户端源码在 tactile-research/，预构建产物在 dist/tactile-lab/。修改客户端后在其目录执行 npm ci、npm run build，主平台仍由 Python 本地服务或静态 Sites 提供。
平台未复用源包的 Site ID、身份配置、D1/R2 绑定或任何运行数据。来源及第三方许可见 THIRD_PARTY_NOTICES.md 与 tactile-research/SOURCE.json。
